## 添加截图

1. 截取对应功能的图片
2. 调整为合适的尺寸（建议宽度 800-1200px）
3. 保存为 PNG 格式
4. 替换占位符文件

## 截图规范

- 格式：PNG
- 建议尺寸：宽度 800-1200px，保持宽高比
- 建议文件大小：< 500KB
